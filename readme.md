## About Me

I'm a Cyber Security student working towards becoming an Offensive Cloud Security Engineer & Security Auditor, with a focus on ethical hacking, security testing, vulnerability research, cloud security, and GRC.

I started my career as a mechanical plumber and, since 2022, I've traded blueprints and shifters for VMs, Kali, a mouse and keyboard, and the questionable decision to voluntarily test human and AI-built systems and applications instead of plumbing problems.

It’s definitely a different approach to a career change. Apparently, leaking pipes weren't enough for me. These days, I'm looking for leaks in places where what's flowing through them can be just as valuable as water is to infrastructure and vegetation.

The difference is that when a pipe leaks, you can usually see it. In cyber security, the leaks can be hidden behind applications, networks, identities, cloud infrastructure, and configuration.

That’s what drew me to the field: understanding how systems work, finding where they can fail, testing those weaknesses responsibly, and helping build and secure systems that are harder to break.
